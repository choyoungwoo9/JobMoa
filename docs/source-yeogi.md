# 여기어때 수집 규칙

이 문서는 현재 구현 범위와 **2026-11-21 읽기 전용 사이트 확인**을 기록한다. 코드 등록은 실제 수집 성공을 뜻하지 않는다.

## 포털과 후보 범위

공식 [여기어때 채용 Greeting 포털](https://gccompany.career.greetinghr.com/ko/apply)을 대상으로 한다. 이전에 등록했던 `internship.yeogi.com`은 다른 주소로, 403 실패의 원인이었다. 현재 페이지의 서버 렌더링 `openings` 데이터에서 `deploy=true`, 마감되지 않은 공고 중 공식 직군이 `기술`이고 제목이 개발·엔지니어 역할로 명확한 항목만 후보에 넣는다. 분석·기획·운영·보안 및 비개발 분야는 현재 지원 범위가 아니다. 상세는 같은 Greeting 포털의 공고 ID로 확인한다.

## 공통 단계

- 목록에서 얻은 상세 URL은 해당 어댑터의 허용 호스트·경로로 검증한다. 상세 제목과 목록 제목을 대조하고 충분한 본문이 렌더링되지 않으면 실패 처리한다.
- Greeting 공통 파서가 상세 ID·제목·본문을 대조하고 `status` 및 명시적 마감일을 확인한다. 목록에서 사라짐·접근 차단·일반 HTTP 오류만으로 마감 처리하지 않는다.
- 회사별 후보 조건은 어댑터에, 최종 분야 분류는 `CategoryClassifier`와 [분류 규칙](classification-rules.md)에 둔다. 현재 이 사이트는 개발 8개 분야와 전체 수집만 지원하고 비개발 분야는 지원하지 않는다.
