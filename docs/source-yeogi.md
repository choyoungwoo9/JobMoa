# 여기어때 수집 규칙

이 문서는 현재 구현 범위와 **2026-11-21 읽기 전용 사이트 확인**을 기록한다. 코드 등록은 실제 수집 성공을 뜻하지 않는다.

## 포털과 후보 범위

사용자가 제공한 공식 2026 채용연계 인턴 페이지 `internship.yeogi.com`을 대상으로 일반 브라우저 접근 및 화면 링크 추출만 시도한다. 개발·데이터 엔지니어·인프라·보안 엔지니어 계열 제목만 허용하고 분석·기획·운영은 제외한다. Cloudflare 보안 확인은 우회하지 않는다.

## 공통 단계

- 목록에서 얻은 상세 URL은 해당 어댑터의 허용 호스트·경로로 검증한다.
- 상세 제목과 목록 제목을 대조하고 충분한 본문이 렌더링되지 않으면 실패 처리한다.
- 명시적 종료 상태나 마감일만 마감 증거로 쓴다. 목록에서 사라짐·접근 차단·일반 오류만으로 마감 처리하지 않는다.
- 회사별 후보 조건은 어댑터에, 최종 분야 분류는 `CategoryClassifier`와 [분류 규칙](classification-rules.md)에 둔다. 현재 이 사이트는 개발 8개 분야와 전체 수집만 지원하고 비개발 분야는 지원하지 않는다.
