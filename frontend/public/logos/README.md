공식 이미지 로딩에 실패하면 기업군의 문자 마크를 대신 표시한다. 새 사이트를 등록할 때는 로고 파일과 이 표의 출처를 함께 추가한다. `npm run build`는 모든 사이트 항목에 로고 파일과 이 문서의 파일 링크가 있는지 검사한다. 갱신 시 공식 페이지에서 자산 주소를 다시 확인하고 변경 출처를 이 문서에 반영한다.

2026-11-16 수정: 네이버 기업 홈페이지의 검정 N 대신 네이버 서비스의 초록 N을 사용한다. 오늘의집은 파란 배경에 파란 집 심볼이 묻히던 표시를 흰 배경의 공식 앱 아이콘으로 교체했다. 기업군 배경도 흰색으로 두어 집 모양을 가리지 않는다.

검증: 2026-11-16 실제 실행 화면에서 두 파일 정상 로딩과 초록색 N/흰 배경 집 심볼 표시를 확인했다.
